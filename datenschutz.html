Datenschutzerklärung

Claude Kontakte ist eine private Anwendung für den Eigengebrauch des Kontoinhabers. Es gibt keine weiteren Nutzer.

Welche Daten werden verarbeitet?

Die Kontakte im Google-Konto des Kontoinhabers (z. B. Namen, E-Mail-Adressen, Telefonnummern, Geburtstage, Adressen) sowie die E-Mail-Adresse des angemeldeten Kontos.

Wofür?

Ausschließlich, damit der Kontoinhaber seine eigenen Kontakte auf seinem eigenen Computer lesen, anlegen, ändern und in persönlichen Notizen ablegen kann.

Wo werden die Daten verarbeitet?

Die Verbindung zu Google läuft über ein Programm auf dem Computer des Kontoinhabers. Die Zugangsdaten werden nur dort gespeichert. Es gibt keinen Server des Anbieters, und Daten werden weder verkauft noch an Dritte weitergegeben. Der Kontoinhaber nutzt für die Bearbeitung einen KI-Assistenten nach eigener Wahl.

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.

Nutzung von Google-Daten

Die Nutzung der über Google APIs erhaltenen Daten entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).
